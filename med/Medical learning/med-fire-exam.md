# Exam Forecast Skill

เก็งจุดที่น่าจะออกสอบจากเนื้อหาบรรยาย แล้วบีบให้เหลือ keyword สั้นสุดที่จำได้เร็วที่สุด — ไม่ใช่สรุปเนื้อหาซ้ำ

---

## หลักการสำคัญ

**เป้าหมาย**: ตอบคำถาม "ถ้าจะออกสอบจากเนื้อหานี้ จะออกตรงไหน" ไม่ใช่สรุปทุกอย่างที่มีในไฟล์

**สัญญาณว่าจะออกสอบสำคัญกว่าความสำคัญทางวิชาการ** — จุดที่อาจารย์พูดเน้นย้ำหรือบอกตรงๆ ว่าออกบ่อย มีน้ำหนักสูงกว่าข้อเท็จจริงที่ถูกต้องแต่ไม่ถูกเน้น แม้จะดูเป็นรายละเอียดเล็กน้อยในสไลด์

**ความสั้นคือคุณภาพ** — เหมือน med-keyword: keyword ที่ดีคือสั้นที่สุดที่ยังจำได้ถูก

---

## ขั้นตอน

### 1. อ่านทั้งไฟล์ก่อนเลือก
อย่าเลือกจุดจาก topic แรกๆ จนครบโควตาแล้วข้าม topic หลัง — ต้องเห็นภาพรวมทุก topic ก่อน แล้วค่อยกระจายน้ำหนัก

### 2. ไล่หาสัญญาณตามลำดับความสำคัญ

**Priority 1 — บอกตรงว่าออกสอบ** (น้ำหนักสูงสุด เก็บทุกจุดที่เจอ):
- คำตรงๆ เช่น "ออกข้อสอบบ่อย", "ออกบ่อยมาก", "classic", "สเต็มข้อสอบคลาสสิค", "จำเพาะมาก", "อาจารย์เน้นย้ำ"
- มักอยู่ใต้หัวข้อ 🎯 (เช่น "🎯 แนวทางการเรียนและการสอบ", "🎯 จุดเน้นย้ำและแนวข้อสอบ") — สแกนหาหัวข้อเหล่านี้ก่อนเป็นอันดับแรก

**Priority 2 — Spoken Pearl อื่นๆ**:
- เนื้อหาใต้ 🎙️ Spoken Pearls ที่อาจารย์อธิบายเพิ่มจากคำพูด ไม่ได้อยู่ในสไลด์ตรงๆ — มักเป็นจุดที่ข้อสอบชอบออกเพราะเป็นสิ่งที่ "แยกคนฟังบรรยายกับคนอ่านสไลด์อย่างเดียว"

**Priority 3 — จุดจำเพาะในเนื้อหาสไลด์**:
- ตัวเลขเด่น, ลักษณะจำเพาะที่ใช้ diagnosis (เช่น ลักษณะภาพ imaging, pathology finding เฉพาะโรค), ตัวย่อ, differentiator ระหว่างโรคที่คล้ายกัน

**Priority 4 — fallback เท่านั้น**:
- ถ้าเก็บจาก Priority 1-3 ยังไม่ครบจำนวนที่ขอ ค่อยใช้ข้อเท็จจริงพื้นฐานทั่วไปเติม และ **บอกผู้ใช้ตรงๆ ว่าจุดไหนเป็น fallback** อย่าเนียนใส่ปนโดยไม่บอก

### 3. กระจายตาม topic ตามน้ำหนักที่อาจารย์เน้น
ไม่ต้องแบ่งเท่ากันทุก topic — topic ที่มี Priority-1 signal เยอะควรได้โควตามากกว่า topic ที่ไม่มีเลย

### 4. เลือกจำนวนตามที่ผู้ใช้ระบุ
ถ้าผู้ใช้บอกจำนวน (เช่น "15 ข้อ") ให้ยึดตามนั้น ถ้าไม่ระบุ default 10-15

### 5. แปลงเป็น keyword format
ใช้หลักการเดียวกับ med-keyword skill:

| บริบท | Style |
|--------|-------|
| มีรูปร่าง/ภาพชัดเจน | Mnemonic/ภาพจำ |
| ตัวเลข/เกณฑ์วินิจฉัย | Bullet กลไกสั้น พร้อมตัวเลข |
| แยกโรคคล้ายกัน | Key differentiator (A vs B) |
| ประวัติ/อาชีพจำเพาะ | Pattern trigger (ประวัติ + ตรวจพบ) |

---

## Format output

```
**[TOPIC ตามที่ปรากฏในไฟล์ต้นฉบับ]**
* 🔥 [Concept] = [Keyword สั้นสุด]: [อธิบาย ≤1 บรรทัด] *(เน้นย้ำว่าออกสอบ)*
* [Concept] = [Keyword]: [อธิบาย ≤1 บรรทัด] *(spoken pearl)*
* [Concept] = [Keyword]: [อธิบาย ≤1 บรรทัด] *(สไลด์)*
```

- ใช้ 🔥 นำหน้าเฉพาะจุดที่มาจาก Priority 1 (บอกตรงว่าออกสอบ) เท่านั้น เพื่อให้เห็นชัดว่าอันไหนควรจำก่อน
- ท้ายแต่ละบรรทัดใส่ที่มาสั้นๆ ในวงเล็บเอียง เพราะนี่คือการ "คาดการณ์" ไม่ใช่เฉลยที่ยืนยันแล้ว ผู้ใช้ควรรู้ว่าจุดไหนมั่นใจสูง/ต่ำ
- ปิดท้ายด้วยจำนวนรวมที่ส่งมอบ เทียบกับที่ขอ (เช่น "รวม 15/15 ข้อ" หรือถ้าไม่ครบเพราะเนื้อหาไม่พอ ให้บอกตรงๆ)

## กฎเหล็ก

- **ห้ามอธิบายยาว** — เกิน 1 บรรทัดต่อจุดต้องตัด
- **ห้ามเลือกจุดที่ไม่ถูกเน้นเลย** เว้นแต่เป็น fallback ที่ระบุไว้ชัดเจน
- **อย่าสรุปเนื้อหาทั้ง topic ซ้ำ** — เลือกเฉพาะจุดที่มีโอกาสเป็นคำตอบ/ตัวลวงในข้อสอบจริง
- **ภาษาผสมได้** — ไทย + อังกฤษ ใช้แบบที่จำง่ายกว่า ตามสไตล์ med-keyword
- **ถ้าไฟล์มีหลาย topic ใหญ่ ต้องมีอย่างน้อย 1 จุดจากแต่ละ topic** เว้นแต่ topic นั้นไม่มีสัญญาณเน้นย้ำเลยจริงๆ (ให้บอกด้วยว่าข้ามเพราะอะไร)
